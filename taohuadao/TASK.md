## 二、頁面結構（仿 cialispros + 桃花島主題化）

### 2.1 首頁 / index.html
- **Nav：** Logo（桃花島書法字）+ 導覽（首頁 / 商品 / 購物須知 / 客服蓉兒 / 貨態查詢）
- **Hero：** 水墨潑彩全屏背景，動態桃花飄落粒子，標題「桃花島」毛筆字體
- **商品列表：** 卡片式，每張卡片垂直排列圖＋名稱＋價格＋加入購物車
- **浮動客服按鈕：** 右下角蓉兒頭像，點擊開啟 AI 對話視窗

### 2.2 商品頁 / goods/[id].html（仿 cialispros 佈局）
- 上方：大圖直式展示（產品包裝圖）
- 規格表：成分 / 每粒容量 / 製造廠商 / 保存期限
- 價格 + 「立即訂購」按鈕（金色，水墨暈染 hover 效果）
- 手風琴 Q&A：常見問題展開/收合
- 使用說明 / 注意事項段落
- 底部：相關商品推薦

### 2.3 AI 客服視窗（蓉兒）
- 右下角浮動 FAB，點擊展開對話框（350px 寬，水墨邊框）
- 蓉兒頭像 + 名字顯示在對話氣泡上方
- **蓉兒口吻範例：**
  - 「蓉兒在這裡～有什麼要問的嗎？😏」
  - 「這個嘛，靖哥哥都說這個效果很好呢！」
  - 「別害羞，蓉兒什麼都懂的！」
- 預設 FAQ 快捷按鈕（如：怎麼訂購 / 幾天到貨 / 安全嗎）
- 串接 Claude / Gemini API（key 從環境變數讀取）

## 三、視覺設計規格

### 色盤（彩色水墨）
```
桃紅（主色）：  #E8547A
翠綠（輔色）：  #4A9B6F
金黃（點綴）：  #C9A84C
靛藍（深色）：  #2B4B7E
米白（背景）：  #FBF6EE
墨黑（文字）：  #1A1209
```

### 字型
- 標題：Google Fonts「Noto Serif TC」（思源宋體，接近毛筆質感）
- 副標 / 正文：「Noto Sans TC」
- 英文：「EB Garamond」

### 水墨效果技術
- 桃花飄落：CSS `@keyframes` 動畫，SVG 桃花形狀
- 水墨暈染邊框：`box-shadow` + SVG filter blur 模擬
- 背景：SVG 潑墨筆觸層疊（漸層 + svg feTurbulence filter）
- 按鈕 hover：ink-spread 效果（`clip-path: circle()` 展開動畫）
