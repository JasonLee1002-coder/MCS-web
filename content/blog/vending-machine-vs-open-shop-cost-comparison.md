## 創業前最關鍵的抉擇：開店還是買販賣機？

「我有50萬想創業，要開店還是買販賣機？」

這是銓幻元科技客服每週都會收到的問題。兩種創業模式表面上都是「賣食物賺錢」，但財務結構、風險特性、生活方式的影響完全不同。

本文從數字角度徹底拆解，讓你用客觀數據做決策。

## 財務結構完整對比

### 一、初期投資比較

#### 開一間小吃店/咖啡廳
| 項目 | 費用範圍 |
|------|---------|
| 店面裝潢 | 30-100萬元 |
| 廚房設備 | 20-50萬元 |
| 押金（3-6個月租金） | 9-30萬元 |
| 開業行銷費用 | 5-20萬元 |
| 備料/進貨 | 3-8萬元 |
| 雜費（執照、保險等） | 2-5萬元 |
| **合計** | **69-213萬元** |

#### 購入冷凍微波販賣機
| 項目 | 費用範圍 |
|------|---------|
| 設備購入（TH-21MS） | 30-50萬元 |
| 場地保證金 | 1-5萬元 |
| 初期進貨 | 1-3萬元 |
| 安裝費（通常含在設備費中） | 0-2萬元 |
| **合計** | **32-60萬元** |

#### 租賃方案（月費制）
| 項目 | 費用範圍 |
|------|---------|
| 前期費用 | 5-10萬元 |
| 月費（設備+維護） | 8,000-15,000元/台 |

**結論：** 初期資本需求，販賣機比開店低 50-70%。

### 二、每月固定成本

#### 實體小吃店（10坪，月租3萬，1名員工）
| 項目 | 月費用 |
|------|-------|
| 店面租金 | 30,000元 |
| 員工薪資（1名） | 30,000元 |
| 電費+水費 | 8,000元 |
| 食材成本（佔營收40%）| 依營收而定 |
| 其他雜費 | 5,000元 |
| **固定成本合計** | **73,000元以上** |

#### 1台冷凍微波販賣機
| 項目 | 月費用 |
|------|-------|
| 場地費 | 3,000-8,000元 |
| 電費 | 500-1,500元 |
| 補貨人力（兼職分攤）| 1,000-2,000元 |
| 維修費用（分攤） | 500-1,000元 |
| **月固定成本** | **5,000-12,500元** |

**⚠️ 關鍵差距：** 實體店月固定成本是販賣機的 **6-15倍**

### 三、損益平衡點

#### 實體小吃店（月固定成本7.3萬+食材成本40%）
- 損益平衡每月營業額：**12.2萬元**
- 相當於每天需要營業額 **4,066元**
- 以每客均價 80 元計算：每天需要 **51 位客人**

#### 1台販賣機（月固定成本8,000元+商品成本40%）
- 損益平衡每月營業額：**13,333元**
- 相當於每天需要營業額 **444元**
- 以每客均價 120 元計算：每天需要 **4 位顧客**

**結論：** 販賣機的損益平衡門檻極低，只需少量客流即可盈利。

## 三、風險比較

### 實體店的風險結構

**不可控風險（最致命）：**
- 鄰居開了同類型競爭店 → 客流量腰斬
- 房東不續租或漲租 → 被迫搬遷（裝潢成本全損）
- 食安問題（員工操作不當） → 聲譽永久損傷

**每月損失情境（生意差的月份）：**
- 即使完全沒有客人，仍需支付 7.3 萬元固定成本
- 6 個月不盈利就燒掉 43.8 萬元

### 販賣機的風險結構

**可控風險（多數可轉移）：**
- 設點地點不好 → 申請遷機到更好地點
- 某台機器銷售不好 → 調整商品組合或遷機
- 設備故障 → 銓幻元技術團隊協助排障

**每月損失情境（生意差的月份）：**
- 月固定成本約 8,000 元
- 6 個月不盈利損失約 4.8 萬元（約為開店的 1/9）

## 四、生活方式影響

### 開店業主的日常

- 營業時間：每天 10-14 小時在店內
- 假日：幾乎無法休假（休假 = 零收入）
- 管理壓力：員工出缺勤、食材新鮮度、客訴處理
- 健康風險：長期站立、高溫廚房作業

### 販賣機業主的日常

- 時間自由度極高：每週補貨 2-3 次（可彈性安排）
- 假日可以自由規劃（機器持續運轉賺錢）
- 管理壓力低：IVM 雲端平台遠端監控，手機即可掌握所有機器狀況
- 可擴展性強：一個人可以管理 10-15 台機器

## 五、擴張速度比較

### 開店擴張

第一家店盈利後 → 積累資金（約 2-3 年）→ 開第二家店（需再投入 100-200 萬）

**從 1 家到 3 家：約 5-8 年**

### 販賣機擴張

第一台盈利後 → 用收益購入第 2 台（約 6-12 個月）→ 再擴至 5 台、10 台

**從 1 台到 10 台：約 2-3 年**

## 什麼情況下開實體店比販賣機更好？

儘管數字對販賤機非常有利，但以下情況開實體店仍有優勢：

1. **品牌建立目標**：需要打造實體品牌形象、創造可讓人「朝聖」的特色空間
2. **高度個人化服務**：精緻料理、手工甜點等需要「人」傳遞的獨特體驗
3. **飲食體驗場景**：餐廳的社交屬性（約會、聚餐）是販賣機無法取代的
4. **地方商圈主導**：熟悉特定社區，有穩定熟客基礎

## 混合模式：餐廳 × 販賣機

越來越多業者採用「混合模式」，同時獲得兩種優勢：

- **餐廳作為品牌旗艦**：提供完整用餐體驗、建立品牌知名度
- **販賣機作為延伸通路**：24小時販售招牌料理冷凍包、在其他場地設點拓展銷售範圍

東方美早餐連鎖品牌就是典型案例：用 200+ 門市建立品牌，同時導入 GraBox 智取櫃延長每間門市的服務時間、降低尖峰人力需求。

## 決策建議

**選擇販賣機，如果你：**
- 初始資本有限（50 萬以下）
- 重視時間自由和生活品質
- 想要低風險、可擴展的創業模式
- 沒有特定技術（廚藝）或品牌資產

**選擇開店，如果你：**
- 有獨特配方或技術，需要「製作過程」展示
- 有充足資本（100 萬以上）和 3 年以上心理準備
- 目標是打造知名本地品牌
- 享受與顧客面對面互動的體驗
