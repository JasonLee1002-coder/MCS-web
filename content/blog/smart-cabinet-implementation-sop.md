# 5 步驟快速導入智取櫃：從評估場地到首日營運的完整 SOP

## 導入智取櫃沒有想像中困難

很多餐飲業者對智取櫃有興趣，但擔心導入過程太複雜、會影響現有營運。事實上，從決定導入到正式營運，最快**兩週內**就能完成。

本文整理完整的導入 SOP，讓你一步步照著做，不走彎路。

## Step 1：場地評估與需求確認（1-2 天）

### 場地條件確認

在選定放置智取櫃的位置前，確認以下條件：

| 項目 | 要求 | 備註 |
|------|------|------|
| 空間 | 寬 80cm × 深 70cm × 高 180cm 以上 | 含操作空間與散熱空間 |
| 電源 | 110V/220V 專用插座 | 冷藏/冷凍型需 220V |
| 網路 | Wi-Fi 或有線網路 | 雲端管理與推播通知必需 |
| 動線 | 顧客可自然接近、不阻擋通道 | 靠近出餐口最佳 |
| 環境 | 室內、避免陽光直射與雨淋 | 延長設備壽命 |

### 需求規格確認

與設備商討論以下問題：

1. **日均出餐量**是多少？→ 決定格口數量（12/18/24 格）
2. **餐點溫度需求**？→ 常溫、冷藏、冷凍或混合
3. **現有 POS 系統**是什麼品牌？→ 確認串接方式
4. **付款方式**需要支援哪些？→ 行動支付、信用卡、員工卡等
5. **是否需要人臉辨識**取餐功能？

> 銓幻元科技提供免費場地評估服務，由專業團隊到現場勘查並提出建議。歡迎[聯繫我們](/#contact)預約。

## Step 2：設備訂製與系統配置（3-7 天）

### 設備端

- 根據 Step 1 的需求確認，訂製合適的 [GraBox 智取櫃](/products/grabox) 規格
- 外觀客製（品牌 LOGO、配色）
- 溫層配置（常溫/冷藏/冷凍比例）

### 系統端

- **POS 系統串接**：技術團隊與你的 POS 廠商對接
- **KDS 設定**：廚房顯示系統與智取櫃連動
- **會員系統整合**：如有既有會員 APP，進行 API 串接
- **推播設定**：SMS、LINE、APP 推播管道設定
- **雲端後台建立**：管理帳號、權限、數據看板

系統串接的技術細節可參考 [POS/KDS 系統整合指南](/blog/smart-cabinet-pos-kds-integration)。

## Step 3：設備安裝與測試（1-2 天）

### 安裝流程

1. **設備進場**：專業團隊搬運、定位、固定
2. **電力接線**：接電、測試供電穩定性
3. **網路連線**：連接 Wi-Fi 或有線網路，測試連線品質
4. **系統初始化**：登入雲端後台、設定基本參數
5. **溫度校準**：確認各格口溫度達標

### 全流程測試

安裝完成後，進行**完整的模擬營運測試**：

- [ ] POS 下單 → 訂單傳送到 KDS → 廚房備餐 → 放入格口 → 顧客取餐
- [ ] 推播通知是否正常發送
- [ ] 人臉辨識登錄與取餐測試
- [ ] 行動支付與其他付款方式測試
- [ ] 溫度監控數據是否正常回傳
- [ ] 逾時未取餐的自動處理機制
- [ ] 雲端後台數據是否即時更新

> **建議**：測試階段讓內部員工先體驗 1-2 天，收集使用回饋後再正式上線。

## Step 4：員工教育訓練（半天）

智取櫃導入後，最需要訓練的是**廚房與外場人員**：

### 廚房人員訓練重點

- 如何在 KDS 上查看智取櫃訂單
- 備餐完成後如何分配到正確格口
- 溫度異常警報的處理流程
- 食材效期管理與補貨時機

### 外場/管理人員訓練重點

- 雲端後台操作（查看銷售數據、庫存狀態）
- 顧客引導話術（教顧客第一次使用）
- 常見問題排除（格口卡住、網路斷線等）
- 日常清潔與保養 SOP

### 顧客引導方案

第一次使用智取櫃的顧客可能不熟悉操作，建議：

- **前兩週**安排一位人員在旁引導
- 在智取櫃旁張貼**簡單圖示說明**
- 透過 LINE 或 APP 推送使用教學
- 首次使用給予小優惠，降低心理門檻

## Step 5：正式營運與持續優化

### 首日營運檢查清單

- [ ] 所有格口溫度正常
- [ ] POS → KDS → 智取櫃 流程順暢
- [ ] 推播通知正常發送
- [ ] 支付系統正常運作
- [ ] 有人員現場支援引導

### 第一週：密切監控

- 每日查看雲端後台數據
- 記錄顧客反饋與常見問題
- 調整格口分配策略（熱門時段多分配格口）
- 確認補貨頻率是否合適

### 第一個月：數據優化

- 分析**尖峰時段**與**熱門品項**
- 優化**備餐節奏**，減少顧客等待時間
- 根據取餐數據調整**格口溫層比例**
- 評估是否需要增加格口數量

### 持續營運

- **每週**：查看銷售報表、清潔保養
- **每月**：商品組合調整、系統更新
- **每季**：效益評估、考慮擴充或新增據點

## 常見問題 FAQ

**Q：導入期間需要停止營業嗎？**
A：不需要。設備安裝通常安排在離峰時段或休息日，系統測試可與現有營運並行。

**Q：現有員工需要學很久嗎？**
A：基本操作訓練約 2-3 小時即可上手。系統設計以直覺操作為目標，學習曲線很低。

**Q：如果設備故障怎麼辦？**
A：台灣在地製造的好處就是快速回應。銓幻元科技提供全台售後服務，故障排除有明確的 SLA 時效。

**Q：可以先租再決定是否購買嗎？**
A：歡迎[聯繫我們](/#contact)討論租賃方案。

## 結語

智取櫃導入不是一個大工程，而是一個**有章法的 5 步驟流程**。最關鍵的是 Step 1 的需求確認——把需求想清楚，後面就是執行。
