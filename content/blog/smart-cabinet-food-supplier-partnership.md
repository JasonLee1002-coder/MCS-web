# 食品廠商合作 GraBox 智取櫃：開拓無人通路的完整指南

## 無人通路，食品廠商的藍海機會

台灣冷凍食品市場正在經歷結構性變化。傳統通路（超市、便利商店）的競爭激烈、帳期長、下架率高；而**智取櫃與冷凍販賣機**構成的「無人通路」，正成為食品廠商拓展業績的新選項。

對食品廠商而言，無人通路的優勢在於：
- **毛利高於傳統通路**：不需要支付通路上架費、無下架壓力
- **帳期短**：銷售即回款，無庫存壓力
- **直達終端消費者**：工廠宿舍、醫院、辦公大樓——這些場域的消費者在固定時間有固定需求
- **數據透明**：IVM系統提供即時銷售數據，快速了解哪個品項在哪個場域最熱銷

## 智取櫃 vs 冷凍販賣機：兩種合作模式

### 模式一：冷凍微波販賣機供貨

**商品流向**：食品廠商 → 冷凍販賣機 → 消費者自助購買微波加熱

最適合的食品類型：
- 冷凍便當、拉麵、烏龍麵
- 炸雞、鹽酥雞等炸物類
- 湯品（需有密封包裝，微波安全）
- 御飯糰、飯糰類

**商品規格要求**：

| 項目 | 規格要求 |
|------|---------|
| 尺寸 | 格口限制（約寬20×深25×高20cm） |
| 重量 | 單份建議300g以下 |
| 包裝 | 微波安全包裝，可承受-18°C冷凍 |
| 標示 | 成分、保存方式、廠商、保存期限 |
| 認證 | 食品工廠登記（必要）；HACCP（部分場域需要） |

### 模式二：GraBox 智取櫃供貨

**商品流向**：食品廠商 → 廚房備餐/分裝 → 放入 GraBox 格位 → 消費者掃碼取餐

GraBox 智取櫃更像是「最後一哩取餐系統」，適合有中央廚房的食品廠商或餐飲業者：
- 提供企業團膳（每日固定送餐至辦公大樓的 GraBox）
- 為醫院提供每日配送的病患餐飲
- 為學校提供預訂制午餐供應

這種模式下，食品廠商不只是「供貨商」，而是完整的「餐飲解決方案提供者」，可以談更好的合作條件。

## 場域特性與商品策略配對

### 工廠/製造業場域

**目標消費者**：夜班工人（需要深夜熱食）

最適商品：
- 雞腿便當（最高需求，量大）
- 滷肉飯、排骨飯類
- 泡麵升級版（冷凍拉麵，口感遠優於泡麵）

注意事項：
- 工廠員工對價格敏感，建議控制售價在$100～120
- 份量要夠，工人體力消耗大

### 醫院場域

**目標消費者**：大夜班護理師、住院病患家屬

最適商品：
- 清淡便當（照顧醫護健康需求）
- 粥品/米食（病患家屬需求）
- 飲料、甜點（下午茶點心）

注意事項：
- 醫院場域通常要求 HACCP 認證
- 食品必須清楚標示熱量、成分（醫護人員健康意識高）

### 辦公大樓/科技園區

**目標消費者**：加班的上班族（尤其是深夜、假日需求）

最適商品：
- 高端便當（客單價可達$150～200）
- 日式拉麵、咖哩飯（品質感商品）
- 甜點、下午茶類（零食市場）

注意事項：
- 上班族消費能力強，可嘗試較高客單價品項
- 差異化選品（不要跟超商撞）是關鍵

## 合作申請流程

### 標準流程

```
1. 提交合作申請（官網表單）
   ↓
2. 初步洽談（了解廠商背景、商品類型、產能）
   ↓
3. 樣品評測（口感、包裝、微波加熱效果測試）
   ↓
4. 合格商品列入合作清單
   ↓
5. 試運行（指定場域1個月試賣）
   ↓
6. 數據檢討（銷售數據分析、消費者反饋）
   ↓
7. 正式長期合作
```

### 樣品評測標準

- **口感**：從冷凍狀態微波加熱後，口感是否達到商業標準（測試人員評分）
- **包裝完整性**：冷凍後包裝是否變形、破損
- **加熱時間**：是否在3分鐘內完成加熱
- **食安文件**：必要認證文件齊全

## 收益試算：食品廠商角度

### 情境A：批發供貨給販賣機業者

假設：日均銷售30份、批發單價$60、生產成本$40

| 項目 | 計算 |
|------|------|
| 月銷售量 | 30份 × 30天 = 900份 |
| 月批發營收 | 900份 × $60 = $54,000 |
| 月生產成本 | 900份 × $40 = $36,000 |
| **月毛利** | **$18,000** |

### 情境B：廠商自購設備＋自行選址

假設：日均銷售40份、售價$130、毛利率50%

| 項目 | 計算 |
|------|------|
| 月營收 | 40份 × $130 × 30天 = $156,000 |
| 月毛利（50%） | $78,000 |
| 扣除場地費、電費、補貨 | -$15,000 |
| **月淨利** | **$63,000** |

廠商自行掌握通路，利潤顯著更高，但需要承擔設備投資和選址風險。

## 適合合作的廠商類型

**最適合的合作夥伴**：

- **中央廚房業者**：有穩定供貨能力、可提供客製規格
- **冷凍食品加工廠**：已有冷凍生產線，可快速導入
- **連鎖餐飲品牌**：想拓展外帶通路、不增加店面的品牌
- **食品貿易商**：代理進口冷凍食品，尋找新的銷售通路

**不適合的廠商**：產品保存期限短（7天以內）、無法穩定供貨、商品不符合微波加熱標準。
