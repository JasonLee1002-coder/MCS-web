# MCS 銓幻元 — AI 及平台管理中心

## 定位

MCS（銓幻元科技）的核心 SaaS 平台，是所有自助設備的「神經中樞」。
讓 2 個人就能管理一整間餐廳。

## 主要功能

### 全流程串接
```
顧客進場
  → Kiosk 點餐 / QR 桌邊點餐
  → MCS 後台派單
  → 蒸煮機備餐 + 茶飲機出杯
  → GraBox 冰櫃入庫
  → 顧客掃碼取餐
  → LINE Pay 結帳
  → 數據回傳
  → AI 分析優化菜單
```

### 管理功能
- **即時庫存監控**（所有設備統一顯示）
- **遠端補貨提醒**（設備低庫存自動通知）
- **銷售數據分析**（品項、時段、客流）
- **AI 菜單優化**（根據銷售數據建議調整）
- **多點管理**（同時管理多家門店）

### 設備串接
- GraBox 冷凍 / 常溫智取櫃
- 自助智慧茶飲機
- 桌上型奶茶機
- 桌上蒸煮拉麵機
- 自助咖啡機（WMF 德國商用級）
- Kiosk 自助繳費訂餐機
- 自助微波取餐櫃
- 觸控螢幕智慧販賣機

## 商業模式

- **SaaS 月費**（每門店）
- **設備銷售 + 維護**（硬體收入）
- **數據服務**（總部 AI 分析報告）
