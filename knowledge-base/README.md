# CMO 知識庫

MCS 銓幻元 × CMO 行銷長 — AI 知識資本化系統

## 目的

把所有對話、文件、分析資料結構化存儲，
讓 CMO AI 和未來的知識查詢平台能快速檢索。

## 目錄

```
knowledge-base/
  _schema.md              # 文件格式規範
  README.md               # 本文件

  products/               # 產品知識
    grabox.md             # GraBox 雙面智取櫃（完整規格、場景、競爭優勢）
    mcs-platform.md       # MCS AI 管理中台（功能、商業模式）
    self-service-devices.md # 九大自助設備陣列

  clients/                # 客戶檔案
    east-beauty.md        # 東方美 × MCS（千店計畫、旗艦店、策略）
    huangweide.md         # 黃維德藥師 / 普健生醫（SEO 客戶）

  market/                 # 市場研究
    satellite-scenarios.md # GraBox 8 大衛星部署場景分析

  projects/               # 專案狀態
    mcs-web.md            # MCS 官網（mcstation.ai）現況

  strategy/               # 策略文件
    mcs-business-model.md # MCS 商業模式（飛輪、供應鏈、加盟）
```

## 更新原則

- 每次對話有重大新資訊 → CMO 立刻更新對應文件
- 新客戶/新產品 → 新增對應 .md 文件
- 資料以最新 `last_updated` 日期為準
