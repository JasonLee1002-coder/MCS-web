# 黃維德藥師 AI 行銷平台 — 後續方向與角色分析

> **日期：** 2026-05-22
> **依據：** 會議紀錄 + Jason LINE 補充 + 普健生醫背景

---

## 一、平台核心定位

**「AI 放大藥師專業，讓在地藥局被更多人找到」**

不是「AI 取代行銷」，而是：
- AI 負責：**大量、快速、結構化**地產生初稿
- 行銷負責：**方向、策略、法規校正、個別化**
- 藥師負責：**專業背書、在地知識、最終審核**

---

## 二、平台架構（三層）

```
┌─────────────────────────────────────────────────┐
│               Layer 1：知識輸入                    │
│  藥局 TA 資料 + 主推品項 + 法規資料庫 + 症狀主題     │
└──────────────────────┬──────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────┐
│               Layer 2：AI 產製引擎                 │
│  症狀支線生成 → SEO 文章 → 社群貼文 → FAQ          │
└──────────────────────┬──────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────┐
│               Layer 3：人工審稿閘門                │
│  行銷審稿 → 藥師確認 → 法規檢查 → 正式發布          │
└─────────────────────────────────────────────────┘
```

## 三、角色分工（5 個角色）

### 角色 1：行銷策略師（詩娟 / 行銷主管）

**職責：**
- 分析各藥局 TA（年齡、地區、常見症狀、消費習慣）
- 確定每個藥局的主力主題（如：A 藥局主打過敏、B 藥局主打銀髮族關節）
- 規劃症狀主題樹（主題 → 支線 → 文章數量）
- 審稿：內容方向、TA 對齊、SEO 關鍵字確認
- 法規紅線把關（禁用詞檢查）

**工具：**
- 藥局 TA 資料表（每間藥局一份）
- 症狀支線地圖（AI 輔助產出初版，人工確認）
- 法規禁字資料庫

---

### 角色 2：AI 產文引擎

**職責：**
- 根據行銷策略師提供的「症狀 + TA + 商品方向」生成初稿
- 產出格式：SEO 文章、社群貼文（FB/IG/LINE）、FAQ、影片腳本
- 自動套用法規過濾規則（禁字替換）
- 批次產文（每次可產 10-30 篇初稿）

**限制：**
- 不直接發布，只輸出草稿
- 不聲稱療效，只描述「舒緩、調理、保養」
- 不連結金流頁面

---

### 角色 3：藥師審核員（黃維德 / 在地藥師）

**職責：**
- 確認文章內容的**專業正確性**
- 確認商品描述符合該藥局的實際庫存/品項
- 確認無**法規違規風險**
- 提供在地知識補充（如：「這區老人多，加關節保健品的連結」）
- 最終簽核（approve）

**重要：** 每間合作藥局的審核人可以是該藥局的駐點藥師，不必全部回到黃總

---

### 角色 4：技術維運工程師（Jason / 外部協力）

**職責：**
- 建立與維護 AI 產文平台（huangweide-seo + 後台）
- 處理 API 串接異常
- SEO 技術排查（404、sitemap、robots、Core Web Vitals）
- Vercel 部署維護
- 法規資料庫建立與更新

**重要建議：** 需建立**值班制度**或**問題回報 SLA**，讓行銷端知道出問題找誰、多久解決

---

### 角色 5：法規顧問（兼職 / 建議）

**職責：**
- 定期更新各地衛生局裁罰案例
- 建立並更新「AI 禁字規則資料庫」
- 遇到邊界情況時的最終裁定
- 建議由具有食藥署法規背景的人擔任（可能是黃總本人或委外）

**短期替代方案：** 行銷主管 + 黃總藥師背景先承擔，長期建議獨立化

## 四、內容策略框架

### 症狀主題樹（示範）

```
過敏（主題幹）
├── 過敏性鼻炎
│   ├── 早晨噴嚏不停（台北都市型）
│   ├── 換季過敏怎麼辦
│   └── 兒童過敏性鼻炎
├── 異位性皮膚炎
│   ├── 嬰幼兒濕疹
│   ├── 成人搔癢
│   └── 不吃藥的保養方式
└── 皮膚過敏（接觸性）
    ├── 對金屬過敏
    └── 化妝品過敏

每個支線 → 1 篇 SEO 文章 + 1 篇 IG/FB 社群貼文 + 1 個 FAQ
```

**一個主題幹可以產出 30-50 篇內容**

## 七、技術平台規劃

### 短期（1-3個月）
- 現有 `huangweide-seo` Next.js 網站 → 擴充部落格功能
- 建立後台管理介面（草稿管理、審核流程）
- 整合 AI 產文 API（Claude / GPT-4）
- 法規禁字自動過濾

### 中期（3-6個月）
- 多藥局管理功能（每間藥局獨立設定）
- 社群自動排程（Buffer / Hootsuite 整合）
- Local SEO 儀表板（Google Search Console + GMB）

### 長期（6個月+）
- 藥局 SaaS 化（可開放給其他藥局訂閱使用）
- AI 個人化內容引擎（根據藥局 TA 自動調整風格）

## 九、商業模式思考

目前這套「AI + SEO + 藥局個別化」模式，**本身可以是一個 SaaS 產品**：

- 目標客群：台灣 6,000+ 社區藥局
- 痛點：缺乏數位行銷人力、不懂 SEO、害怕法規風險
- 價值：每月固定費用，獲得 AI 產文 + SEO + 法規保護

**這個方向值得跟 CPO 討論是否要產品化。**
